# زارت · پیام‌رسان

این پروژه یک اپلیکیشن پیام‌رسان یک‌صفحه‌ای است که با HTML/CSS/JavaScript ساخته شده و برای اجرای روی Railway آماده شده است.

**Status:** ✅ فعال و آماده برای استفاده

## آماده‌سازی برای Railway

1. فایل‌های زیر به پروژه اضافه شده‌اند:
   - `package.json`
   - `server.js`
   - `railway.json`
   - `.gitignore`

2. سرور از طریق Express اجرا می‌شود و فایل `messenger (2).html` سرو می‌شود.

3. برای استارت پروژه، دستور زیر اجرا شود:
   ```bash
   npm install
   npm start
   ```

4. بعد از اجرای محلی، آدرس زیر در دسترس است:
   - http://localhost:3000

## انتشار روی Railway

1. وارد سایت Railway شوید و حساب بسازید.
2. در داشبورد روی New Project کلیک کنید.
3. گزینه GitHub Repo را انتخاب کنید.
4. مخزن پروژه را انتخاب کنید و به Railway متصل کنید.
5. Railway به‌صورت خودکار پروژه را شناساخت می‌کند؛ اگر نه، فایل‌ها را روی GitHub آپلود کنید.
6. در صفحه deploy، اگر پروژه به‌درستی تشخیص داده شود، Railway به‌صورت خودکار `npm install` و `npm start` را اجرا می‌کند.
7. برای فعال‌سازی Health Check، مسیر `/health` آماده است.

## نکات مهم

- اگر Railway به‌صورت رایگان از شما می‌خواهد که GitHub را وصل کنید، این نیاز است.
- به‌صورت رایگان، در Railway فقط سرویس‌های محدود ممکن است فعال باشند؛ با این حال برای پروژه‌ی ساده‌ی HTML/JS این کافی است.
- برای ساختن URL نهایی، Railway در نهایت یک دامنه اختصاصی می‌دهد.
