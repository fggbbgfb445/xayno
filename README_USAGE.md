## 2️⃣ **PWA - نصب روی گوشی** (بدون APK)

### 📱 اندروید
1. سایت را در **Chrome** باز کنید
2. منوی 3 نقطه (⋮) بالا سمت راست
3. کلیک روی **"Install app"** یا **"Add to Home screen"**
4. **اپ نصب شد!** از صفحه اصلی باز کنید

### 🍎 آیفون
1. سایت را در **Safari** باز کنید
2. دکمه **Share** (اشتراک‌گذاری) را کلیک کنید
3. **"Add to Home Screen"** را انتخاب کنید
4. **نام اپ را بنویسید** و Done
5. **اپ نصب شد!** از صفحه اصلی باز کنید

### ✅ مزایا

## 3️⃣ **اپ اندروید (APK)** (برای اندروید فقط)

### 📥 ساخت APK

#### **گام 1: نصب ابزارهای لازم**

خواندن فایل [`SETUP_ANDROID.md`](SETUP_ANDROID.md) برای نصب:
- Java Development Kit (JDK)
- Android Studio
- SDK

#### **گام 2: ساخت APK**

بعد از نصب ابزارها:

```powershell
cd android

# برای تست (Debug APK)
gradlew.bat assembleDebug

# برای انتشار (Release APK)
gradlew.bat assembleRelease
```

#### **گام 3: APK کجا است؟**

**Debug APK:**
```
android/app/build/outputs/apk/debug/app-debug.apk
```

**Release APK:**
```
android/app/build/outputs/apk/release/app-release.apk
```

#### **گام 4: نصب روی گوشی**

1. فایل `.apk` را به گوشی منتقل کنید
2. APK را باز کنید
3. مجوزهای لازم را تأیید کنید
4. **نصب انجام شد!**

### ✅ مزایا
- ✔ اپ واقعی
- ✔ می‌توان در گوگل پلی انتشار داد
- ✔ بدون نیاز به سایت
